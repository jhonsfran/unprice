Add local mode for budgets. In a long-lived process, `unprice.budget(key, { mode: "local", lease: { amount } })` returns a handle whose `authorize`, `settle`, `release`, `charge`, and `spend` answer in memory against a lease the API debits up front, with the same results as the remote handle; `record` and `get` stay remote. The handle reports consumption every `flushIntervalMs` (1 s), tops the lease back up below `lowWater`, and returns it after `idleMs` (10 s) with no spending and no open hold. A client holds one lease per key however many handles it takes, and `unprice.close()` returns every open lease, resolving with the keys it could not return; a lease never closed expires after `ttlMs` (60 s) and counts in full. `ttlMs` must exceed three flush intervals, and after a refused lease the key answers with that denial from memory for one flush interval. The client also accepts `waitUntil` and `onSettleError`: with `waitUntil`, `spend` returns as soon as the work finishes and settles in the background, and a settle that fails goes to `onSettleError` while its hold expires at its full estimate. `unprice.budgets.lease` and `unprice.budgets.report` are the operations local mode uses.
