---
title: Replay ingestion events
description: Replay failed ingestion events with a stored payload.
---

Use `ingestionEvents.replay` after you inspect an ingestion failure. Replay only events that are
marked replayable. The operation queues the stored payload again; it does not create a new usage
event from the dashboard state.

```ts
const { result, error } = await unprice.ingestionEvents.replay({
  project_id: "proj_123",
  canonical_audit_ids: ["audit_123"],
})

if (error) throw new Error(`${error.code}: ${error.message}`);

return result;
```

After you queue a replay, call [Ingestion event status](/libraries/ts/sdk/ingestion-events/status)
to confirm the final state.
