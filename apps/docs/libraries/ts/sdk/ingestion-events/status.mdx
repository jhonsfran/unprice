---
title: Ingestion event status
description: Inspect processed, rejected, and failed ingestion events.
---

Use `ingestionEvents.status` to inspect recent usage ingestion. It is an evidence and recovery
operation. It does not authorize customer spend.

Check the returned state before you take action:

- `processed`: Unprice accepted and applied the event.
- `rejected`: Unprice refused the event as a business decision, such as a limit or budget denial.
- `failed`: A system or pipeline error stopped processing. Check whether the event is replayable.

```ts
const { result, error } = await unprice.ingestionEvents.status({
  project_id: "proj_123",
  limit: 50,
})

if (error) throw new Error(`${error.code}: ${error.message}`);

return result;
```

Read [Replay ingestion events](/libraries/ts/sdk/ingestion-events/replay) only for failed events
with a stored replay payload.
