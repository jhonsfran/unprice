---
title: "Update access"
description: "Update explicit access-control overrides for a customer."
---

<RequestExample>

```ts
const { result, error } = await unprice.access.update({
  customerId: "cus_1234567890",
  updates: {
    customerDisabled: true,
    customerUsageLimitReached: false
  }
});

if (error) throw new Error(`${error.code}: ${error.message}`);

return result;
```

</RequestExample>

<ResponseExample>
```json
{}
```
</ResponseExample>

## Request

<ParamField body="customerId" type="string" required>
    The customer ID to update.
</ParamField>

<ParamField body="updates" type="object" required>
    Access-control fields to update for the customer.
</ParamField>

<ParamField body="updates.customerDisabled" type="boolean">
    Disable or re-enable all feature access for the customer.
</ParamField>

<ParamField body="updates.customerUsageLimitReached" type="boolean">
    Set an explicit usage-limit override for the customer. Clear the override when the customer can
    use the feature again.
</ParamField>

<ParamField body="updates.subscriptionStatus" type="string">
    Override the subscription status used for access checks.
</ParamField>

## Response

Returns an empty object on success. Use this operation for an explicit operator override. Do not use
it instead of `usage.consume` or `access.check` in the request path.
