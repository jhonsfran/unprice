---
title: "Check access"
description: "Resolve whether a feature is usable for a customer now."
---

<RequestExample>

```ts
const { result, error } = await unprice.access.check({
  customerId: "cus_1234567890",
  featureSlug: "ai-messages"
});

if (error) {
  console.error(error.message);
  return;
}

console.log(result);
```

</RequestExample>

<ResponseExample>
```json
{
  "featureSlug": "ai-messages",
  "allowed": true,
  "metered": true,
  "usage": 42,
  "limit": 100,
  "quotaWindow": {
    "periodKey": "ai-messages:month",
    "startAt": 1793491200000,
    "endAt": 1796083200000
  }
}
```
</ResponseExample>

## Request

<ParamField body="customerId" type="string" required>
    The customer ID to check.
</ParamField>

<ParamField body="featureSlug" type="string" required>
    The feature slug to check.
</ParamField>

## Response

A metered feature answers from the customer's subscription budget, live. A flat, seat, or package
feature answers from the customer's plan.

<ResponseField name="allowed" type="boolean" required>
    Whether the customer may use the feature now.
</ResponseField>

<ResponseField name="featureSlug" type="string" required>
    The feature slug that was checked.
</ResponseField>

<ResponseField name="rejectionReason" type="string">
    Why the feature is not usable: `NO_ENTITLEMENT`, `LIMIT_EXCEEDED`, or `BUDGET_CLOSED`. Omitted
    when `allowed` is `true`.
</ResponseField>

<ResponseField name="metered" type="boolean" required>
    `true` when the customer's subscription budget meters the feature.
</ResponseField>

<ResponseField name="usage" type="number">
    The quantity used in the limit's current window. Present for a metered feature with a limit.
</ResponseField>

<ResponseField name="limit" type="number | null" required>
    The feature's quantity limit, or the subscribed quantity of a seat or package feature. `null`
    means unlimited.
</ResponseField>

<ResponseField name="quotaWindow" type="object | null" required>
    The window the limit counts in: `periodKey` is the limit's id, `startAt` and `endAt` are epoch
    milliseconds, and `endAt` is exclusive (null for a limit that never resets).
</ResponseField>
