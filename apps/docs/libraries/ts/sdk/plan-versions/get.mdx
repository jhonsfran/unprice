---
title: "Get plan version"
description: "Read versioned pricing and feature configuration."
---

```ts
const { result, error } = await unprice.planVersions.get({
  planVersionId: "pv_1234567890"
});

if (error) throw new Error(`${error.code}: ${error.message}`);

return result.planVersion;
```

## Request

<ParamField path="planVersionId" type="string" required>
  The plan version ID to retrieve.
</ParamField>

## Response

`result.planVersion` contains the requested version, including its plan,
feature configuration, meter definitions, currency, billing settings, and publication status.
Timestamps ending in `AtM` use epoch milliseconds. Trial length uses `trialUnits`: minutes for minute-billed plans, days for all other
billing intervals.

For the complete response schema, use the [API reference](/api-reference/plans/get-version).
For versioning behavior, read [Plans and versions](/concepts/pricing/plans).
