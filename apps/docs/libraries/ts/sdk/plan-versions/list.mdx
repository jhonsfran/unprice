---
title: "List plan versions"
description: "Read versioned pricing and feature configuration."
---

```ts
const { result, error } = await unprice.planVersions.list({
  onlyPublished: true,
  onlyLatest: true,
  onlyEnterprisePlan: false,
  billingInterval: "month",
  currency: "USD"
});

if (error) throw new Error(`${error.code}: ${error.message}`);

const planVersions = result.planVersions;
```

## Request

All filters are optional.

| Field | Meaning |
| --- | --- |
| `onlyPublished` | Filter published versions |
| `onlyLatest` | Filter the latest version of each plan |
| `onlyEnterprisePlan` | Filter enterprise plan versions |
| `planVersionIds` | Restrict the result to specific version IDs |
| `billingInterval` | `month`, `year`, `week`, `day`, `minute`, or `onetime` |
| `currency` | `USD` or `EUR` |

## Response

`result.planVersions` contains the matching versions, including its plan,
feature configuration, meter definitions, currency, billing settings, and publication status.
Timestamps ending in `AtM` use epoch milliseconds. Trial length uses `trialUnits`: minutes for minute-billed plans, days for all other
billing intervals.

For the complete response schema, use the [API reference](/api-reference/plans/list-versions).
For versioning behavior, read [Plans and versions](/concepts/pricing/plans).
