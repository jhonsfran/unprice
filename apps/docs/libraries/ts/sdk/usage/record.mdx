---
title: "Record usage"
description: "Record up to 100 usage events that already happened, priced into each customer's billing period."
---

<RequestExample>

```ts
const { result, error } = await unprice.usage.record({
  events: [
    {
      idempotencyKey: "evt_01J9Z3",
      eventSlug: "completions",
      customerId: "cus_1234567890",
      occurredAt: Date.now(), // Persist this event time and key for retries.
      properties: {
        inputTokens: 1840,
        outputTokens: 620,
        model: "gpt-4.1-mini",
      },
    },
  ],
});

if (error) {
  console.error(error.message);
  return;
}

for (const event of result.results) {
  if (event.status === "rejected") console.warn(event.idempotencyKey, event.error.reason);
}
```

</RequestExample>

<ResponseExample>
```json
{
  "accepted": 1,
  "rejected": 0,
  "results": [
    {
      "status": "accepted",
      "customerId": "cus_1234567890",
      "idempotencyKey": "evt_01J9Z3",
      "amount": "0.0042",
      "crossed": [],
      "replayed": false
    }
  ]
}
```
</ResponseExample>

## Request

<ParamField body="events" type="array" required>
    1 to 100 events. Each one goes to its customer's subscription budget, which prices it when it
    arrives.
</ParamField>

<ParamField body="events[].idempotencyKey" type="string" required>
    Up to 256 characters, usually the event id. A retry with the same key and the same event
    replays the first answer (`replayed: true`) and counts once.
</ParamField>

<ParamField body="events[].eventSlug" type="string" required>
    The event a metered feature of the customer's plan listens to, for example `completions`.
</ParamField>

<ParamField body="events[].occurredAt" type="number" required>
    When the usage happened, in epoch milliseconds. At most 24 hours old. The usage counts in the
    billing period that contains it, or in the next open period when that one is already sealed.
</ParamField>

<ParamField body="events[].customerId" type="string">
    The customer ID. Required when the API key has no default customer binding.
</ParamField>

<ParamField body="events[].properties" type="object">
    Flat strings, numbers, booleans, or null, at most 4 KB. The meter reads the quantity and the
    dimensions (such as `model`) from them.
</ParamField>

## Response

The call answers 200 with one result per event, in request order. Recorded usage always counts,
even past a limit, because the work already ran; `crossed` names the limits it passed. A refused
event carries the error a single call would return in `error`, and the other events still count:

| `error.reason` | `error.status` | Meaning |
| --- | --- | --- |
| `NOT_PRICED` | 400 | No rate on the plan's rate card matches the event |
| `UNKNOWN_EVENT` | 400 | No metered feature of the plan takes the event slug |
| `INVALID_OCCURRED_AT` | 400 | `occurredAt` is in the future |
| `TOO_LATE` | 409 | `occurredAt` is more than 24 hours old |
| `PERIOD_CLOSED` | 409 | The billing period is sealed and no later one is open |
| `NO_STATEMENT` | 409 | No billing period covers the event |
| `IDEMPOTENCY_CONFLICT` | 409 | The key was used for another event |
| `BUDGET_NOT_FOUND` | 404 | The customer has no subscription yet |
| `CUSTOMER_FORBIDDEN` | 403 | The API key is bound to another customer (`error.code` is `FORBIDDEN`) |
| `BUDGET_UNAVAILABLE` | 503 | The customer's budget could not be reached, so the event was not counted (`error.code` is `UNAVAILABLE`). Retry it with the same idempotency key |

`usage.record` does not block paid work. Use [`usage.consume`](/libraries/ts/sdk/usage/consume)
to admit work only when it fits.
