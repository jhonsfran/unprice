---
title: "Consume usage"
description: "Price one usage event and count it only if it fits, before the work runs."
---

<RequestExample>

```ts
const { result, error } = await unprice.usage.consume({
  idempotencyKey: "req_8f2c",
  eventSlug: "completions",
  customerId: "cus_1234567890",
  properties: {
    inputTokens: 1840,
    outputTokens: 620,
    model: "gpt-4.1-mini",
  },
});

if (error?.code === "BUDGET_EXCEEDED") {
  return new Response("Usage limit reached", { status: 429 });
}
if (error) {
  throw new Error(`${error.code}: ${error.message}`);
}

console.log(result.amount);
```

</RequestExample>

## Request

<ParamField body="idempotencyKey" type="string" required>
    Up to 256 characters. A retry with the same key and the same event replays the first answer
    (`replayed: true`) and counts once.
</ParamField>

<ParamField body="eventSlug" type="string" required>
    The event a metered feature of the customer's plan listens to, for example `completions`. One
    event can feed several features.
</ParamField>

<ParamField body="customerId" type="string">
    The customer ID. Required when the API key has no default customer binding.
</ParamField>

<ParamField body="properties" type="object">
    Flat strings, numbers, booleans, or null, at most 4 KB. The meter reads the quantity and the
    dimensions (such as `model`) from them.
</ParamField>

## Response

The customer's subscription budget prices the event at the current time and counts it only if it
fits every hard limit. `amount` is what it cost, in the budget's unit.

| Status | Error code | When |
| --- | --- | --- |
| 402 | `BUDGET_EXCEEDED` | A hard limit has no room (`details.blocked` names it), or a prepaid wallet cannot fund the event |
| 400 | `BAD_REQUEST` | No rate prices the event (`NOT_PRICED`), or no metered feature takes its slug (`UNKNOWN_EVENT`) |
| 404 | `NOT_FOUND` | The customer has no subscription yet |
| 409 | `CONFLICT` | The key was used for another event, the billing period is closed, or the subscription ended |
