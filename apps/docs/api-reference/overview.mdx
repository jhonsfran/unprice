Call the Unprice API from trusted server-side code. It authorizes customer spend, records usage,
and returns evidence for the decision.

All public endpoints use this URL pattern:

```
https://api.unprice.dev/{version}/{service}/{method}
```

For example, `GET /v1/plan-versions/get/{planVersionId}` returns a plan version.

Send your project API key in the `Authorization` header. Read [Authentication](/api-reference/authentication)
before you call an endpoint.

## HTTP methods

The public API uses `GET` and `POST`. It does not use `PUT` or `DELETE`.

### `GET`

`GET` methods are used for reading data. Filtering, sorting, or pagination is done via query parameters.

```http
curl "https://api.unprice.dev/v1/plan-versions/get/pv_123" \
  -H "Authorization: Bearer <API_KEY>"
```


### `POST`

Use `POST` to create, change, or apply data. Send request data as `application/json`.

```http
curl -X POST "https://api.unprice.dev/v1/plan-versions/list" \
  -H "Authorization: Bearer <API_KEY>"
  -H "Content-Type: application/json"
  -d '{
    "onlyPublished": true,
    "onlyEnterprisePlan": false,
    "onlyLatest": true,
    "billingInterval": "month",
    "currency": "USD"
  }'
```
