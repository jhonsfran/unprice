---
title: TOO_MANY_REQUESTS
openapi-schema: ErrTooManyRequests
---

## Cause

The API key sent too many requests in a short time.

## Action

Wait before you retry. Reduce concurrent requests or request a higher rate limit for the key when
the traffic is expected.

## Support evidence

Include the error response and `requestId` if you contact [support](mailto:seb@unprice.dev).
