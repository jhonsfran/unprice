---
title: FORBIDDEN
openapi-schema: ErrForbidden
---

## Cause

The API key is valid, but it cannot access the requested project, customer, or operation.

## Action

Use a key for the correct project. If the key is bound to a default customer, do not use it to
spend for another customer.

## Support evidence

Include the error response and `requestId` if you contact [support](mailto:seb@unprice.dev).
