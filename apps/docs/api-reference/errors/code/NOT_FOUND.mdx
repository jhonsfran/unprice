---
title: NOT_FOUND
openapi-schema: ErrNotFound
---

## Cause

The requested resource does not exist in this project, or the identifier is incorrect.

## Action

Check the resource ID and project API key. Create the resource before you request it when the
operation requires an existing resource.

## Support evidence

Include the error response and `requestId` if you contact [support](mailto:seb@unprice.dev).
