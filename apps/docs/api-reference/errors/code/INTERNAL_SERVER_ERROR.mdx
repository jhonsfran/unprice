---
title: INTERNAL_SERVER_ERROR
openapi-schema: ErrInternalServerError
---

## Cause

Unprice could not complete the request because of an unexpected server error.

## Action

Do not change the request. Retry only when the operation is idempotent. For usage and run calls,
reuse the same idempotency key.

## Support evidence

Include the error response and `requestId` if you contact [support](mailto:seb@unprice.dev).
