## Cause

The request is valid, but a required project or resource condition is not met. For example, the
project can lack a required published plan or configuration.

## Action

Read the error message. Complete the named setup step, then repeat the request.

## Support evidence

Include the error response and `requestId` if you contact [support](mailto:seb@unprice.dev).
