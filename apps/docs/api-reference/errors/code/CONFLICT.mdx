---
title: CONFLICT
openapi-schema: ErrConflict
---

## Cause

The request conflicts with the current resource state. For example, another resource can already
use the identifier, or the resource can already be published.

## Action

Load the current resource state. Use a unique identifier or change the request so it does not
repeat the completed state change.

## Support evidence

Include the error response and `requestId` if you contact [support](mailto:seb@unprice.dev).
