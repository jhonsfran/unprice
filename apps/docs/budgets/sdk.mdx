`@unprice/budgets` is the budget client on its own. `@unprice/api` includes it and re-exports its
handles, errors, and types, so code moves between the two packages by changing the import, and
`instanceof` checks match errors from either.

<CodeGroup>

  ```bash npm
  npm install @unprice/budgets
  ```

  ```bash pnpm
  pnpm add @unprice/budgets
  ```

  ```bash yarn
  yarn add @unprice/budgets
  ```

  ```bash bun
  bun add @unprice/budgets
  ```
</CodeGroup>

```ts
import { Unprice } from "@unprice/budgets";

const unprice = new Unprice({ token: process.env.UNPRICE_TOKEN! });
```

## Operations

`unprice.budgets` calls the API directly. Each method returns `{ result }` or `{ error }`; check
`error` before you use `result`.

| Method | Endpoint |
| --- | --- |
| `budgets.upsert(input)` | `POST /v1/budgets/upsert` |
| `budgets.get({ key })` | `GET /v1/budgets/get` |
| `budgets.authorize(input)` | `POST /v1/budgets/authorize` |
| `budgets.settle(input)` | `POST /v1/budgets/settle` |
| `budgets.release(input)` | `POST /v1/budgets/release` |
| `budgets.charge(input)` | `POST /v1/budgets/charge` |
| `budgets.record(input)` | `POST /v1/budgets/record` |
| `budgets.lease(input)` | `POST /v1/budgets/lease` |
| `budgets.report(input)` | `POST /v1/budgets/report` |

The request and response schemas are in the [API reference](/api-reference/overview).

## Handles

`unprice.budget(key)` returns a handle bound to one key. It never creates or changes the budget.

| Method | Returns |
| --- | --- |
| `spend(input, fn)` | The value your function returns. Throws the [budget errors](/budgets/errors). |
| `authorize({ amount, idempotencyKey, ttlMs? })` | `{ result: { allowed: true, hold } }` or `{ result: { allowed: false, blocked } }` |
| `charge({ amount, idempotencyKey })` | `{ result: { allowed: true, ... } }` or `{ result: { allowed: false, blocked } }` |
| `record({ amount, idempotencyKey, occurredAt })` | `{ result }` with `crossed` |
| `get()` | `{ result: { budget, history } }` |

A hold from `authorize` has `id`, `key`, `amount`, `expiresAt`, `settle({ amount })`, and
`release()`. See [spend against a budget](/budgets/spend).

`unprice.budget(key, { mode: "local", lease })` returns a [local handle](/budgets/local-mode) with
the same methods, plus `flush()` and `close()`. `unprice.close()` returns every open lease and
resolves with the keys it could not return.

Amounts accept numbers or decimal strings and come back as decimal strings. Numbers are rounded to
8 decimal places.

## Errors

| Class | Thrown when |
| --- | --- |
| `BudgetExceededError` | A limit denied the estimate |
| `BudgetUnavailableError` | Unprice could not be reached after the client's retries |
| `BudgetRequestError` | The API rejected the authorization |
| `BudgetRecoveryError` | Your function threw, or your idempotency key replayed |
| `BudgetSettleError` | The work succeeded, but its settle failed |

[Errors and recovery](/budgets/errors) explains each one.

## Client options

<ParamField body="token" type="string" required>
  A project API key. Use a runtime key where the code spends, and a config key only where caps are
  raised.
</ParamField>

<ParamField body="baseUrl" type="string" default="https://api.unprice.dev">
  Send requests to your own Unprice deployment.
</ParamField>

<ParamField body="retry" type="{ attempts?: number; backoff?: (retryCount: number) => number }">
  Retries on network and server errors. `attempts` defaults to 2, so a call makes at most three
  requests.
</ParamField>

<ParamField body="waitUntil" type="(promise: Promise<unknown>) => void">
  Keeps a serverless runtime alive after the response. With it, `spend` returns once your function
  finishes and settles in the background.
</ParamField>

<ParamField body="onSettleError" type="(error: BudgetSettleError) => void">
  Receives a background settle that failed. Its hold stays open and counts its full estimate when
  it expires.
</ParamField>

<ParamField body="fetch" type="(input: Request) => Promise<Response>">
  A custom `fetch` for non-standard runtimes or tests.
</ParamField>

<ParamField body="headers" type="Record<string, string>">
  Additional headers to send with each request.
</ParamField>

<ParamField body="cache" type="RequestCache" default="no-store">
  The `fetch` cache mode.
</ParamField>

<ParamField body="debug" type="boolean" default="false">
  Log retry attempts with `console.debug`.
</ParamField>

<ParamField body="disableTelemetry" type="boolean" default="false">
  Stop sending anonymous telemetry: runtime, platform, and SDK version.
</ParamField>
